关于我

在西安做点工具，写点东西，也持续保持好奇。

你好，我是 Seven。

这里是我的个人工作空间。建它的初衷很简单：想有一个真正属于自己的地方，把日常学到的东西、做的小工具、读后整理的笔记都放进来。

这里都有什么？

  • 文章——围绕工具、AI、编程、生活方法论的随笔与笔记。
  • 下载——偶尔会用到的脚本、模板、配置资源。
  • 关于——就是你现在看的这一页。

技术说明

整站由 GitHub Pages 托管，纯静态 HTML/CSS/JS，没有广告也没有追踪。内容更新在 GitHub 仓库 完成，推送后由 Jekyll 自动重新构建列表。
