# music/ · 唱片机的音频目录

把你的 MP3（或 m4a / ogg / flac）放进这个目录，然后到
`_data/songs.yml` 里把歌名、歌手、音频文件名对应好，push 之后就会出现在
「唱片机」栏目里。

## 注意事项

- **版权**：只放你有权公开传播的音频。公开仓库里的文件所有人都能下载。
- **体积**：GitHub 单文件上限 100 MB，仓库建议控制在 1 GB 以内。
  一首 320 kbps 的 MP3 大约 8–12 MB，几十首没问题。
- **文件名**：尽量用英文 / 数字，避免中文和空格（比如 `01-blue.mp3`），
  这样链接更稳。
- **封面**：封面图放 `assets/images/covers/`，在 songs.yml 里用 `cover:` 指定文件名。
  不填也没关系，会自动生成色块封面。

## 推荐格式

MP3（128–320 kbps）兼容性最好，浏览器全支持。
